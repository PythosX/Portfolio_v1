# Creative Developer Portfolio — Homepage

A cinematic, dark/deep-red homepage built with React + Vite, CSS, and Framer Motion.

## Run it

```bash
npm install
npm run dev
```

Then open the printed local URL (typically http://localhost:5173).

To build for production:

```bash
npm run build
npm run preview
```

## Replace the placeholder images

`public/images/hero-default.png` and `public/images/hero-hover.png` are
generated placeholder silhouettes (clearly labeled in-image) so the app runs
out of the box. Replace both files with your real character renders,
**keeping the same filenames**, and the hover crossfade will work
automatically. For best results use transparent PNGs with the character
roughly centered and similar framing/scale between the two images, so the
crossfade doesn't shift the silhouette.

## Placeholder content

The About, Projects, and Contact sections below the hero, and the hero's
description copy, are explicitly labeled placeholders — no real project
names, testimonials, or contact details were invented. Swap them for real
content before shipping.
